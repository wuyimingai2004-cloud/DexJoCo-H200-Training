# 训练源码发布范围

来源：[Dex-WAM-RSI](https://github.com/YimingWangMingle/Dex-WAM-RSI) 的 `4a718edf32f3d79d41190e16d5ec5ad9ddcf555f` 工作树，以及 2026-11-09 新增的 DexJoCo 六任务独立四卡训练实现。
这是独立 Git 历史的训练源码子集；原仓库未被推送或改写。

保留六任务数据准备/配置/启动、模型、训练器、离线验证、它们的数据依赖及相关 CPU 测试。
模型测试依赖的动作哈希位于 `execution/trajectory.py`。motus-monitor 仅保留训练侧本地日志/计时 API；其包说明移除了原来的 SSH 部署示例，其他所选训练 Python 源码与原工作树相同。
不包含原项目的机器人执行/RSI 框架、兼容启动器、监控服务/管理界面/远程同步、旧集群下载工具、内部 agent 文档或提交历史。

原配置中的存储路径仅是上游模型结构参考；DexJoCo 配置生成器要求显式提供本次数据、权重和输出目录。
数据、权重、checkpoint、日志、缓存、凭据与原始实验计划文档不包含在仓库中。

第三方源码保留原有文件头与 `UPSTREAM.json` 来源记录；其中源文件哈希对应历史完整快照，部分文件不在本训练子集中。
本仓库未额外赋予第三方组件新的许可证。

本次新增独立的 LeRobot v2 读取器、固定版本第三方 ZIP 下载器及回归测试；未纳入训练数据或权重。
模型结构和优化器配置未更改。数据版本/随机化设置显式写入准备清单和审计记录。
